Mad Max Save Editor

Edits Mad Max (2015) save files. Everything happens in this tab — your save is never uploaded anywhere.

Turn Steam Cloud off for Mad Max before you copy an edited save back. It will quietly put the old one back over yours. Keep a copy of the original either way.
Choose a .sav file, or drop one here.

What has been done

No third-party requests: the Python runtime is served from this site, and there are no fonts, trackers or CDNs. Works offline once loaded.
